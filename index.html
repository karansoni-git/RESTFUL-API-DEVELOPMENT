Library Management API

A fully RESTful API for managing a library system — books, members, loans, and inventory. All responses are JSON. CRUD operations available on all resources.

Base URL http://localhost:5000/api/v1

Authentication

Info
Development Mode: This API currently runs without authentication for local development. For production, add JWT bearer tokens by including Authorization: Bearer <token> in every request header.

Error Codes

Reference

All errors return a consistent JSON envelope with a success: false flag and an error object.

BOOK_NOT_FOUND

Book ID doesn't exist (404)

MEMBER_NOT_FOUND

Member ID doesn't exist (404)

LOAN_NOT_FOUND

Loan ID doesn't exist (404)

DUPLICATE_ISBN

ISBN already registered (409)

DUPLICATE_EMAIL

Email already registered (409)

MISSING_FIELDS

Required fields absent (400)

NO_COPIES_AVAILABLE

All copies checked out (409)

LOAN_LIMIT_REACHED

Member at max loans (409)

BOOK_ON_LOAN

Can't delete active loan (409)

ALREADY_RETURNED

Book already returned (409)

INVALID_EMAIL

Bad email format (400)

MEMBER_HAS_LOANS

Active loans block delete (409)

Pagination

Info
All list endpoints support ?page=1&per_page=10. Max per_page is 50. Response includes a meta object with total, pages, page, and per_page.

PUT /books/{id} Update a book ▶

Update any fields on a book. Only include fields you want to change. Adjusting copies_total will recalculate copies_available automatically.

Request
Response 200
PUT /api/v1/books/b001
Content-Type: application/json

{ "copies_total": 8, "genre": "American Literature" }
200Updated book object
404BOOK_NOT_FOUND
DEL /books/{id} Delete a book ▶

Permanently deletes a book. Will fail if any active loans exist for this book.

Warning: All copies must be returned before deleting a book.
Request
Response 200
DELETE /api/v1/books/b003
{ "success": true, "data": { "id": "b003", "deleted": true } }
200Deletion confirmed
404BOOK_NOT_FOUND
409BOOK_ON_LOAN
